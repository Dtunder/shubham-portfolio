## Portfolio lokal starten

Voraussetzung: Node.js und npm.

\`\`\`bash
npm ci
npm run dev
\`\`\`

Für den statischen Build: \`npm run build\`. Vite baut die Seite in \`dist/\`, und das Repository ist für den Unterpfad \`/shubham-portfolio/\` konfiguriert.
